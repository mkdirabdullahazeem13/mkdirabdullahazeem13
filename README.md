## What I've built

**[Irish Rent Trends](https://github.com/mkdirabdullahazeem13/pyspark/tree/main/irish-rent-trends)**:
a PySpark pipeline on two Irish government datasets (rents and house prices).
- Cleaned 674,000 rent rows where about 70% of the values were empty, and fixed place names
  that had no county (139 locations, down to 0)
- Joined rents to regional house prices and found that rents rose faster than house prices in only
  2 of 26 counties between 2015 and 2025
- Quality checks, tests, and a Streamlit dashboard with a findings log

**[Taxi Trips Pipeline](https://github.com/mkdirabdullahazeem13/pyspark/tree/main/taxi-trips-pipeline)**:
a PySpark batch job with schema checks, data quality rules, window functions, and partitioned output.

**[Ask-Out Webpage](https://github.com/mkdirabdullahazeem13/streamlit/tree/main/ask-out-app)**:
a small Streamlit web page for asking someone on a date, which anyone can customise through a settings file
(names, date ideas, times). It emails a confirmation and keeps the email login out of the code.
